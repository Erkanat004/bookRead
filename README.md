# LUMI Reader 1.1

Офлайн-читалка книг, документов, иллюстраций и комиксов для Android. HTML/CSS/JavaScript, PDF.js, Capacitor и fflate. Без регистрации, рекламы, серверов и сетевого разрешения. Android Studio и SDK на ноутбук устанавливать не нужно.

## Скачать и установить APK

1. Откройте [GitHub Actions](https://github.com/Erkanat004/bookRead/actions) → **Build LUMI Reader APK** → последний успешный запуск.
2. В **Artifacts** скачайте **LUMI-Reader-APK** и распакуйте ZIP. Для скачивания нужно войти в GitHub.
3. Передайте `LUMI-Reader.apk` на телефон и откройте файловым менеджером. Разрешите ему установку неизвестных приложений, нажмите **Установить**.
4. Откройте LUMI → **+** → выберите локальную книгу, документ или изображение. После импорта можно читать в авиарежиме.

Для новой сборки выберите **Actions → Build LUMI Reader APK → Run workflow**. Сборка также запускается после изменения `main`. Android-инструменты устанавливаются только на GitHub runner. Исходники находятся в этом репозитории; Node.js 22+ нужен только для разработки интерфейса.

Это APK с отладочной подписью. При повторной облачной сборке ключ может измениться, и Android тогда не разрешит установку поверх прежней версии. Не удаляйте старую установку, если в ней есть нужные закладки/прогресс: удаление стирает данные приложения. Сохраняйте оригинальные книги. Для постоянных обновлений нужен собственный постоянный ключ подписи; не публикуйте его в репозитории. `versionCode` новой версии — 2, `versionName` — 1.1.

## Поддерживаемые форматы

| Формат | Содержимое |
| --- | --- |
| PDF | Исходные страницы с текстом, изображениями, схемами, таблицами и оформлением через PDF.js |
| EPUB | Главы в порядке spine, введение, оглавление EPUB 2/3, иллюстрации, подписи, таблицы, списки, SVG и MathML |
| FB2, FB2.ZIP | Название/автор, аннотация, введение, разделы, иллюстрации, таблицы, примечания и обложка |
| TXT | UTF-8, UTF-16 и Windows-1251; чтение по частям, без загрузки всего файла |
| DOCX | Текст, заголовки, базовые выделения, встроенные растровые изображения, таблицы, сноски и концевые примечания |
| ODT | Текст, заголовки, списки, встроенные изображения и таблицы |
| RTF | Текст, Unicode, базовые выделения, PNG/JPEG-иллюстрации; содержимое ячеек таблиц |
| HTML, HTM | Текст, заголовки, таблицы, списки, встроенные data-изображения, SVG и MathML |
| Markdown, MD | Текст, абзацы и заголовки; исходный Markdown остаётся читаемым |
| CBZ, ZIP с изображениями | Комикс с естественным порядком страниц: 1, 2, 10 |
| PNG, JPG/JPEG, WebP, GIF, BMP | Отдельные изображения как книги из одной страницы |
| ZIP с книгой | Автоопределение EPUB, FB2, DOCX, ODT либо коллекции изображений внутри архива |

Литературные форматы отображаются как адаптивная книга. Полное совпадение сложной вёрстки Word/RTF, плавающих объектов, диаграмм Office, макросов, видео и форм не обещается. Для точного внешнего вида такого документа используйте PDF. RTF WMF/EMF и HTML-картинки из отдельных соседних файлов не декодируются; сетевые изображения не загружаются. PDF с паролем, DRM, DJVU, MOBI/AZW3, KFX, DOC, RAR/CBR пока не поддерживаются.

## Чтение

- Общая библиотека: обложки, поиск названий, сортировка, переименование, подтверждение удаления.
- «Продолжить чтение», сохранение страницы/раздела и прокрутки внутри текстового фрагмента.
- Свайпы, кнопки, ползунок и переход к номеру.
- PDF и изображения: масштаб 100–300%, жест двумя пальцами и прокрутка.
- Текстовые книги: изменение размера текста, прокрутка, оглавление при его наличии.
- Закладки с восстановлением места в текстовом фрагменте.
- Светлая/тёмная темы с сохранением выбора. PDF и фотографии сохраняют собственные цвета.
- Android «Назад»: закрывает диалог, затем читалку, затем приложение.

В EPUB номер означает раздел, а в текстовых документах — стабильный фрагмент. Он может быть длиннее экрана: прокручивайте вниз. Смена размера текста не меняет номера сохранённых фрагментов. PDF пока рисуется на canvas без выделения, озвучивания и поиска по содержимому. В текстовых книгах используется настоящий HTML-текст.

## Большие файлы и хранение

**Искусственного лимита 512 МБ нет.** Размер сам по себе не блокирует импорт. Android потоково копирует файл буфером 64 КБ в приватный каталог `files/books/<UUID>.book`. Исходники не меняются и не удаляются. Старые PDF из версии 1.0 продолжают читаться из `<UUID>.pdf`.

`LumiWebViewClient` обслуживает диапазоны байтов через `RandomAccessFile` с 64-битными смещениями, `Content-Length` и точными `206 Content-Range`. Это перехват внутри WebView, без сетевого сервера и сокетов. PDF.js запрашивает блоки по 256 КБ, TXT — по 32 КБ. ZIP/ZIP64 индексируются отдельно: EPUB загружает выбранную главу и её иллюстрации, CBZ — выбранную страницу. Весь архив не распаковывается. PDF отрисовывает один canvas, ограниченный примерно 6 млн пикселей.

Нужны свободное место для копии файла и память для текущей страницы/главы. Для отдельных распакованных XML/изображений действует рабочий бюджет памяти, зависящий от устройства, чтобы не распаковывать архив-бомбу. FB2, HTML, RTF и XML документов требуют разбора содержимого в памяти. Огромная отдельная глава/картинка может оказаться непосильной, даже если вся книга читается по частям. При обычных ошибках показывается сообщение. Гарантировать любой файл на любом телефоне нельзя.

Метаданные и JPEG-обложки записываются последовательно через Android `AtomicFile`; системное резервное копирование отключено. Нет широких разрешений на память и разрешения `INTERNET`. Worker PDF.js, CMaps, шрифты и WASM включены в APK. EPUB/HTML-скрипты не исполняются; внешние ресурсы не загружаются. Изоляция Android не является отдельным шифрованием книг.

В браузере данные сохраняются в IndexedDB. Очистка данных сайта удаляет тестовую библиотеку. На Android используются приватные файлы и атомарные метаданные.

## Структура

```text
.github/workflows/android.yml     # Node 22, JDK 21, SDK 36; устанавливаемый APK
android/                         # полный Gradle-проект с wrapper
  app/src/main/java/com/lumi/reader/
    MainActivity.java            # регистрация плагина, Android «Назад»
    LumiFilesPlugin.java         # потоковый импорт и атомарные метаданные
    LumiWebViewClient.java       # локальные диапазоны байтов
src/
  main.js                        # библиотека, PDF и общие элементы читалки
  ebooks.js                      # форматы, иллюстрации, оглавление, HTML-санитизация
  archive.js                     # ленивый ZIP/ZIP64 и диапазоны
  storage.js                     # Android / IndexedDB
  model.js                       # форматы, поиск, прогресс и валидация
  style.css, reading.css         # библиотека и типографика двух тем
scripts/assets.mjs               # локальные ресурсы PDF.js
tests/model.test.mjs             # логика библиотеки
tests/archive.test.mjs           # ZIP, пути, кодировки, виртуальный файл 8 ГБ
tests/smoke.cjs                  # сквозной PDF-сценарий
tests/formats.cjs                # 11 типов файлов, изображения, таблицы и оглавление
capacitor.config.json
package.json, package-lock.json
```

## Разработка без Android Studio

```powershell
npm ci
npm run dev
```

Откройте адрес Vite. Для проверки логики и сборки:

```powershell
npm test
npm run build
npm run android
```

Последняя команда обновляет web-ресурсы Android; APK компилирует GitHub Actions. Не запускайте `cap add android`: проект уже включён.

Для необязательных браузерных проверок установите Playwright отдельно: `npm install --no-save playwright`, `npx playwright install chromium`. Запустите `npx vite preview --port 4180`, затем `node tests/formats.cjs`. Для PDF-сценария задайте `LUMI_URL=http://127.0.0.1:4180/` и запустите `node tests/smoke.cjs`. Playwright не входит в приложение.

Проверка виртуального файла 8 ГБ подтверждает 64-битные смещения и запросы диапазонов, а не чтение реальной 8-гигабайтной книги на телефоне. Физический Android-тест требует установки APK.
