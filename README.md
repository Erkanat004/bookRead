# LUMI Reader

Личная офлайн-читалка PDF для Android. HTML, CSS и JavaScript, PDF.js 5 и Capacitor 8. Интерфейс на русском. Android Studio и Android SDK на ноутбуке не нужны.

## Получить APK

1. Откройте репозиторий на GitHub → **Actions** → **Build LUMI Reader APK**.
2. Выберите **Run workflow** → **Run workflow**. Первый запуск также автоматически начинается после загрузки исходников в `main`.
3. Откройте запуск и дождитесь зелёной отметки задания `apk` (обычно несколько минут).
4. Внизу страницы в **Artifacts** скачайте **LUMI-Reader-APK**. Для скачивания артефактов нужно войти в GitHub.
5. Распакуйте ZIP. Внутри находятся **LUMI-Reader.apk** и файл контрольной суммы **SHA256SUMS.txt**.
6. Передайте APK на телефон, откройте через файловый менеджер и разрешите этому менеджеру установку неизвестных приложений. Нажмите **Установить**.
7. Откройте LUMI Reader → **+** → выберите локальный PDF. После импорта можно включить авиарежим: чтение, обложки, закладки и сохранение работают без сети.

Это устанавливаемый APK с отладочной подписью, подходящий для личной первой версии. Google Play и платные сервисы не нужны. При повторной CI-сборке ключ отладочной подписи может измениться; Android тогда не разрешит обновление поверх старой установки. Сохраняйте оригиналы PDF: удаление приложения удаляет его библиотеку, прогресс и закладки. Для постоянных обновлений используйте один собственный ключ подписи и увеличивайте `versionCode` в `android/app/build.gradle`; не публикуйте личный ключ в репозитории.

Если GitHub показывает кнопку включения Actions, включите их для этого репозитория. GitHub-hosted Actions доступны бесплатно для публичных репозиториев; у приватных репозиториев расходуется бесплатный лимит аккаунта. Интернет нужен для сборки и скачивания APK, но не для установленного приложения.

## Что работает

- Библиотека с обложками из первой страницы PDF, поиском и сортировкой.
- Отдельная карточка «Продолжить чтение».
- Импорт через системный выбор файлов Android; множественный импорт в браузерной версии.
- Просмотр страниц: свайп влево/вправо, кнопки, ползунок и переход к номеру.
- Масштаб от 100 до 300%: кнопки и жест двумя пальцами; увеличенную страницу можно прокручивать.
- Сохранение последней успешно отрисованной страницы после каждого перехода.
- Закладки, список закладок, переименование и удаление с подтверждением.
- Светлая/тёмная темы с сохранением выбора. Первый выбор — по системной теме.
- Аппаратная кнопка Android «Назад»: закрывает диалог, затем читалку, затем приложение.
- Проверки формата, ограничение файла 512 МБ и понятные ошибки.

PDF с паролем в первой версии не поддерживаются: приложение объясняет, как импортировать копию без пароля. Поиск ищет названия книг, не текст внутри PDF. PDF сохраняет собственные цвета страниц в обеих темах. Текст на PDF сейчас рисуется на canvas: выделение, озвучивание и поиск текста не реализованы. Обложки и библиотека доступны с названиями для экранного диктора, но сам текст PDF ему недоступен.

## Хранение и производительность

На Android небольшой собственный Capacitor-плагин `LumiFiles` потоково копирует выбранный PDF в `files/books/<UUID>.pdf` внутри закрытого каталога приложения. Исходное имя не используется как путь. Нет разрешений на общий доступ к хранилищу и нет разрешения `INTERNET`. URI выбранного файла используется только во время импорта; постоянный доступ к исходному файлу не требуется. Библиотека и JPEG-обложки сохраняются в `files/library.json` через Android `AtomicFile`; запись идёт последовательно в фоновом потоке. Системное резервное копирование отключено. Это изоляция Android, а не отдельное шифрование: используйте блокировку телефона.

PDF.js получает локальный URL через `Capacitor.convertFileSrc`. В памяти отрисовывается одна страница; canvas ограничен примерно 6 млн пикселей и DPR до 2. Ресурсы PDF.js, worker, CMaps, стандартные шрифты и WASM копируются в APK при сборке. Приложение не использует CDN, внешние шрифты, аналитику или серверы. Сложные сканы могут требовать больше времени и памяти даже при ограничении canvas; 512 МБ — лимит импорта, не гарантия работы каждого PDF на любом телефоне.

В режиме браузерной проверки файлы и метаданные хранятся в IndexedDB; запрашивается persistent storage. Браузер может очистить данные сайта, поэтому этот режим предназначен для разработки. Основной результат — Android APK с нативным приватным хранилищем.

## Структура проекта

```text
.github/workflows/android.yml       # облачная сборка APK: Node 22, JDK 21, SDK 36
android/                           # полноценный Capacitor Android-проект и Gradle wrapper
  app/src/main/java/com/lumi/reader/
    MainActivity.java              # регистрация плагина и кнопка «Назад»
    LumiFilesPlugin.java           # импорт, приватные файлы, атомарные метаданные
  app/src/main/res/                # иконка, экран запуска, темы Android
src/
  main.js                          # интерфейс, импорт, PDF.js, жесты и закладки
  storage.js                       # Capacitor / IndexedDB и очередь сохранения
  model.js                         # поиск, прогресс, валидация
  style.css                        # адаптивная библиотека и читалка, две темы
scripts/assets.mjs                 # локальные ресурсы PDF.js
scripts/branding.py                # необязательная регенерация иконок, требует Pillow
tests/model.test.mjs               # проверка логики данных
tests/smoke.cjs                    # сквозная браузерная проверка, отдельно нужен Playwright
index.html
capacitor.config.json
package.json
package-lock.json                  # фиксированные версии и воспроизводимый npm ci
```

## Проверить интерфейс на ноутбуке

Нужен только Node.js 22+ (без Java, Android Studio и SDK).

```powershell
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. В браузере можно импортировать настоящие PDF и проверить сохранение после обновления страницы.

```powershell
npm test
npm run build
```

`npm run build` создаёт `dist/` со всеми ресурсами для офлайн-работы. `npm run android` обновляет web-ресурсы Android-проекта; компиляция APK выполняется workflow. Не запускайте `cap add android` повторно: Android-проект уже включён.

Для сквозной проверки дополнительно установите Playwright (не требуется для сборки приложения): `npm install --no-save playwright`, затем `npx playwright install chromium`. После `npm run build` запустите `npx vite preview` и в другом терминале `node tests/smoke.cjs`. Скриншоты попадут в `test-results/`.

## Проверить APK на телефоне

1. Добавьте обычный PDF, многостраничный скан и файл с кириллицей в имени.
2. Перейдите на другую страницу, поставьте закладку, закройте приложение полностью и откройте снова: книга, страница и закладка должны сохраниться.
3. Проверьте свайпы, масштаб, поворот экрана, ползунок и переход по номеру страницы.
4. Включите тёмную тему и авиарежим, перезапустите приложение и откройте книгу.
5. Попробуйте отменить выбор файла, добавить повреждённый PDF и защищённый паролем PDF.
6. Переименуйте, найдите и удалите книгу. Проверьте, что исходный PDF не удалён.
